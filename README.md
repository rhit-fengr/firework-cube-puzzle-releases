## Installation and saved progress

The official-site **Direct** edition uses `com.independent.fireworkcubepuzzle.direct`. It is a separate installation from the Google Play edition and does not automatically import its save or purchases. Keep your existing Play app installed.

An update to an existing Direct installation must retain the original signing certificate. Do not uninstall an older Direct app or clear its storage to work around a signature error. Contact [Support](https://fireworkcubepuzzle.com/support).

Original Direct certificate SHA-256:

```text
6ADB1089C015FCB4B40366B2B50D4E5A6BB80F0DB4BC726037135DA46B9D4AB7
```

Release assets include `SHA256SUMS.txt` and a signed `direct-release.json`. Use the official website's pinned release verification and compare the APK hash before installing.

## Repository scope

This public repository contains distribution information and release attachments only. The game source code, Unity project, build credentials, signing keys and private development history are not published here. GitHub's automatically generated source archives contain only this repository's public documentation, not the game project. Public download access does not make the game open source.
